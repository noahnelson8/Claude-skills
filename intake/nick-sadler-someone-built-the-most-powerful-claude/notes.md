# RuFlow (Ruflo, formerly claude-flow): 60 agents in parallel
**Source:** Nick Sadler · https://www.instagram.com/reel/DWNB0t9iMhv/ · 2026-03-22

**What it actually shows:** A hype voiceover. 60 agents (plan, code, test, security) run in parallel with shared memory and "get smarter every run". It claims to cut Claude API costs 75% by sending simple tasks to cheaper models, and says the project has 14k stars.

**Named things to verify:** The repo is real: `ruvnet/ruflo` (MIT, ~82k stars now; the reel's 14k is from March). The 75% figure is the project's marketing. Cost routing only applies if you pay per API call; on a Claude subscription there's nothing to save.

**Engagement bait?** Yes ("type flow").

**Verdict:** SKIP. This is the reel behind Skip #14, and that verdict stands: heavy multi-agent orchestration, overkill for solo projects.
