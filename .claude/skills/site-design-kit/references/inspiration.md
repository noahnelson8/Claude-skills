# Where to look for references

Pick 2–3 that fit the page, look at the best matches, and borrow **structure and feel**, never copy text, logos or imagery. From the Hugo Manning reel and batch-1 triage; see `intake/` in the claude-skills repo.

| Source | Best for | Notes |
|---|---|---|
| **Awwwards** (awwwards.com) | Award-level hero motion, bold layouts, experiences | High-end; filter by "Sites of the Day" and by category. Good for ScrollCraft-lead pages |
| **curated.design** | Hand-picked real websites with clean taste | Good default for portfolios and brand pages |
| **Saaspo** (saaspo.com) | SaaS landing pages specifically | Best fit for FLUXPROMPT / product pages: hero, pricing, feature grids |
| **Unsection** (unsection.com) | A library of individual sections | Use when you need "a great testimonial / pricing / FAQ section", not a whole page |
| **Details.so** | Micro-interactions and tiny details | Hover states, toggles, cursor effects; the polish layer |
| **Spell UI** | Polished copy-paste components | Components to adapt; check each one's license before shipping |
| **Bencho** | 140+ UI sounds | Sounds are on its paid plan; sound is opt-in and never autoplays |
| **Pinterest** | Mood, colour and photography direction | Underrated for mood boards; search "<industry> web design" |
| **MotionSites** (motionsites.ai) | Finished designs with motion | The 16 free ones are bundled in `vendor/motionsites/examples/`; the rest are on the site |
| **Land-book / Lapa Ninja / Godly** | More landing-page galleries | Extra options when the above don't fit |

## Picking by page type
- **Funnel / lead page (Enhanced.AI, IME, MAR, Big-Box):** Saaspo + Unsection + one MotionSites hero. Clarity first.
- **Brand / product story:** Awwwards + curated.design, ScrollCraft lead.
- **Portfolio:** curated.design + MotionSites portfolio examples.
- **SaaS product page:** Saaspo + Spell UI components, UI UX Pro Max lead.
